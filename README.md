# MilaanSutra

Premium Indian matrimony app. One Expo codebase for Android, iOS, and web.

Product rules, the brand palette, and the screen-by-screen workflow live in [docs/PRODUCT_DESIGN_BRIEF.md](docs/PRODUCT_DESIGN_BRIEF.md).

The current login screen is scaffolding. It is not the approved design.

## Run

```bash
npm install
npx expo start
```

Open the web preview, an Android emulator, or Expo Go from the terminal output. Routes live in `src/app`. API calls belong in `src/lib/api`. Leave `EXPO_PUBLIC_API_URL` empty until a server exists (see `.env.example`).
